❓ 使用說明

    

      設定流程

      ① 左側「＋樓層」新增樓層（如 2F）

      ② 樓層旁「＋」新增區域，填入名稱、Key、Excel Sheet 名稱

      ③ 點選區域 → 上傳該區域平面圖底圖

      ④ 切換「✏️ 新增點位」模式，點擊底圖設定點位

      ⑤ 右側面板編輯每個點位的編號/名稱/ID

      ⑥ 點位可拖曳移動微調

      ⑦ 重複 ③~⑥ 完成全部區域

      ⑧「匯出 all_config.json」下載後上傳到 GitHub repo

      ⑨ 底圖另存為 images/[zoneKey].png 一起上傳


      主程式使用

      手機開啟 GitHub Pages 的 index.html，

      自動讀取 all_config.json 和底圖，可直接量測。


      修改點位

      重新開啟 editor.html → 匯入舊 JSON → 修改 → 重新匯出上傳。
